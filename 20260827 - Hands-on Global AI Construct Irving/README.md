## About the Event

Join us for an evening of learning, building, and connecting at Hands-on Global AI Construct Irving.

This hands-on workshop will guide participants through building, testing, and deploying single-agent and multi-agent hosted agents to Microsoft Foundry from Visual Studio Code. Participants will use the Foundry Toolkit for VS Code and the Microsoft Agent Framework for Python.

## Main Workshop

### [Foundry Toolkit + Foundry Hosted Agents Workshop](https://github.com/microsoft-foundry/Foundry_Toolkit_for_VSCode_Lab)

The workshop includes guided labs for creating both single-agent and multi-agent solutions:

- [Single-Agent Lab](https://github.com/microsoft-foundry/Foundry_Toolkit_for_VSCode_Lab/tree/main/workshop/lab01-single-agent)
- [Multi-Agent Lab](https://github.com/microsoft-foundry/Foundry_Toolkit_for_VSCode_Lab/tree/main/workshop/lab02-multi-agent)

## What to Expect

- Hands-on development in Visual Studio Code
- Build and test agents with the Microsoft Agent Framework
- Deploy hosted agents to Microsoft Foundry
- Explore single-agent and multi-agent patterns
- Connect with local AI developers and community members

## Important Note

This is a hands-on workshop, so please **bring your laptop** and complete the prerequisites before the event.

### Prerequisites

- [Python 3.10 or later](https://www.python.org/)
- [Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli)
- [Azure Developer CLI (`azd`)](https://learn.microsoft.com/azure/developer/azure-developer-cli/install-azd)
- [Visual Studio Code](https://code.visualstudio.com/)
- [Foundry Toolkit for VS Code](https://marketplace.visualstudio.com/items?itemName=ms-windows-ai-studio.windows-ai-studio)
- Azure access and a configured [Microsoft Foundry](https://ai.azure.com/) project endpoint
- [Single-Agent Lab prerequisites](https://github.com/microsoft-foundry/Foundry_Toolkit_for_VSCode_Lab/blob/main/workshop/lab01-single-agent/docs/00-prerequisites.md)
- [Multi-Agent Lab prerequisites](https://github.com/microsoft-foundry/Foundry_Toolkit_for_VSCode_Lab/blob/main/workshop/lab02-multi-agent/docs/00-prerequisites.md)
